## 🌟 Highlights

- **Zen Minimalist & Authentic Tactile Experience**: Dark ebony outer frame, bi-conical diamond beads, separation beam with reckoning unit dots, and procedural acoustic ASMR wooden clacks.
- **3-Rod Place-Value Grouping**: Alternating bead hues every 3 rods (Units, Thousands, Millions) for rapid digit reading, with a 1-click toggle to **Uniform Monotone** to protect photographic mental imagery.
- **Full Japanese Curriculum (全国珠算教育連盟基準)**:
  - Reading beads & direct moves
  - Friends of 5 ($+5 - d$ and $-5 + d$)
  - Friends of 10 carries & borrows
  - Mixed combination moves (e.g. $14 - 7$, $13 - 6$)
  - Visual Multiplication (Kake-zan 乗算)
  - Full Division (Wari-zan 除算) with trial quotients and bead subtraction
- **11-Tier Japanese Shuzan Examination Room**:
  - Official Kyu/Dan tests (10th Kyu up to 1st Kyu and **Dan Grandmaster - Hardest Mode**).
  - Authentic vertical columnar Mitori-zan (見取算), Kake-zan (乗算), and Wari-zan (除算).
  - Official Japanese Certificate of Competency (合格証書) with red Hanko stamp.
- **Flash Anzan (暗算)**: High-speed mental number flash workouts with Ghost Abacus visualization.

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/pav-era121/soroban-zen.git
cd soroban-zen

# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

Built with React 19, TypeScript, Tailwind CSS, Web Audio API, and Vite.
